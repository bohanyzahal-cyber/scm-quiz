# בוחן תרגול — ניהול שרשרת ההספקה למנהלים

תרגול למבחן בקורס **ניהול שרשרת ההספקה למנהלים** (בר-אילן, תואר שני, סמסטר קיץ תשפ"ו), הנלמד במקביל על ידי שני מרצים:
**שלמה ארליך** — תהליכי שרשרת האספקה הארגונית והמודלים הניהוליים (מצגות "שא"), ו**ד"ר ניצן סוויד** — המודלים הכמותיים (חיזוי, מלאי, פארטו, אחזקה, אמינות, חלופות רכש).

**המבחן (לפי הסילבוס): 25 שאלות רב-ברירה, כמותיות ואיכותיות, על כל החומר — 60% מהציון.** ניצן בהרצאה: «במבחן יהיו חישובים, לא מסובכים» — להביא מחשבון.

**▶ [בוחן התרגול](https://bohanyzahal-cyber.github.io/scm-quiz/)** — מצב תרגול עם הסברים, סימולציית מבחן של 25 שאלות, סינון לפי מרצה/נושא, היקף «חישובים בלבד», והדפסה עם תשובות או בלעדיהן.

**▶ [דף נוסחאות ומושגים](https://bohanyzahal-cyber.github.io/scm-quiz/%D7%A0%D7%95%D7%A1%D7%97%D7%90%D7%95%D7%AA.html)** — כל הנוסחאות של ניצן (מצגות 1–11) עם דוגמאות פתורות, שיעורי בית פתורים והערות על טעויות חישוב בשקפים, והמודלים של שלמה בעמוד.

## היקף — מה מכוסה ומה עוד חסר

- **שלמה ארליך — מכוסה במלואו:** כל שמונה מצגות "שא" (מבוא, ניהול חומר, מיקור ורכש, ייצור ומיקור חוץ, הזמנות לקוח, לוגיסטיקה, אסטרטגיה וזמישות, ארגז כלים). השאלות נכתבו מהשקפים עצמם — כולל תרשימים שנבדקו כתמונה (פירמידת רמות מיקור החוץ, עץ העלויות הלוגיסטיות, תוכנית העבודה השנתית ועוד).
- **ד״ר ניצן סוויד — מכוסה במלואו:** כל אחת-עשרה המצגות — אינטגרציה, חיזוי (כולל חיזוי עונתי), רמות מלאי ו-EOQ עם אילוצים, מלאי ביטחון ונקודת הזמנה, פארטו ופילוחים, אחזקה ועלויותיה, אמינות (טור, מקביל, Stand-By), תדירות אחזקה מונעת (מינימום השבתה ומקסימום רווח) ונקודת איזון וחלופות רכש — ובנוסף הדגשים מהקלטות ההרצאות. 92 שאלות חישוב, כל אחת עם פתרון מלא.
- **טעויות חישוב בשקפים של ניצן** (ההסברים ודף הנוסחאות מציינים אותן): מלאי ביטחון בשקף 10 חושב בלי השורש (32.04 ולא 24) ובשקף 15 סטיית התקן היא 365.6 ולא 356.6; אמינות מקבילית בשקפים 19–20 (0.9955 ו-0.9997); S.B בשקף 23 (0.9995); בתדירות אחזקה מונעת, שקף 10 — ‎ln(30) = 3.40‎ ולא 4.6; שקף 35 במצגת האחזקה — 44,400 ולא 14,400; ובמצגת המלאי, שקף 9 — שברי סבבי המלאי והמלאי בשבועות הפוכים.
- **עוד לא נכלל:** הקלטות ההרצאות מ-18.8 ואילך אינן זמינות לסטודנטים באתר הקורס, ולכן הדגשים מהן חסרים. אין באתר הקורס מיקוד או שאלות לדוגמה.
- **מוסכמות ניצן שנבדקו מול השקפים וההקלטות:** ציר X הוא מספר התקופה; בממוצע נע אין תחזית ל-N התקופות הראשונות; בממוצע נע משוקלל עמודת המשקל צמודה לתקופות (1 לאחרונה, ‎−0.1‎ לכל תקופה אחורה) וכל תחזית מתחלקת בסכום המשקולות של החלון; R ולא R²; MAD ו-MSE בלבד.

## בנייה מחדש

```bash
cd src && python build.py
```

`src/build.py` משבץ את `bank*.js` בתוך `src/template.html` וכותב את `index.html` ואת העותק בתיקיית הקורס, ומעתיק את דף הנוסחאות. בכל בנייה רצות בדיקות מבנה (4 אפשרויות שונות, שדות מלאים, אין כפילויות, אין מסיחים תלויי-מיקום) ובדיקת «תל האורך» — שהתשובה הנכונה אינה בולטת כארוכה או כקצרה ביותר.

### כלי כתיבה (`tools/`)

הבנקים 2, 4, 5, 6, 8 ו-11–20 נכתבים כקובצי פייתון ב-`tools/data/` — לכל שאלה התשובה הנכונה ושלושה מסיחים — ו-`tools/mkbank.py` מציב את הנכונה במיקום מאוזן וכותב את `src/bankN.js`:

```bash
cd src && python ../tools/mkbank.py ../tools/data/bank5.py bank5.js && python build.py
```

בבנקים של ניצן (11–20) כל מספר — התשובה, המסיחים (טעויות נפוצות: שכחת השורש, יחידות זמן לא תואמות, עיגול לא נכון, נוסחה של מקרה אחר) והפתרון בהסבר — מחושב בקוד, עם `assert` שמוודא שהמספרים הכתובים בהסבר תואמים לחישוב. עזרים משותפים: `tools/data/calclib.py`. הבנקים 1, 3, 7, 9 ו-10 נערכים ישירות ב-JS.

עזרים: `review.js` מדפיס בנק בצורה קריאה; `rank2.py` ו-`longest.py` מראים איפה הנכונה בולטת באורכה; `arrows.py` מחליף חצים לכיוון הקריאה (← ברצפים עבריים, → רק בין מילים לועזיות). בתוך טקסט עברי, נוסחה נעטפת ב-`<bdi dir='ltr'>` כדי שתוצג משמאל לימין; `mkbank.py` עוטף כך אוטומטית כל רצף לטיני/יווני (אחרת ״ו-μ; 12.50״ מוצג כ״ו-12.50 ;μ״ ו״1/Ф״ כ״Ф/1״), ו-`isofix.py` מחיל את אותו עיבוד על הבנקים שנכתבו ב-JS. `ranks.py` מראה את פיזור אורך התשובה הנכונה בקובץ נתונים.

סכמת שאלה:

```js
{t:"נושא", s:"שלמה | ניצן | הקלטות", q:"השאלה", o:["א","ב","ג","ד"], c:1, e:"הסבר", k:"calc"}
```

`c` הוא אינדקס התשובה הנכונה **לפני** הערבוב (האפליקציה מערבבת את סדר האפשרויות בכל סבב, ולכן אין מסיחים תלויי-מיקום). `k:"calc"` מסמן שאלת חישוב — היא מקבלת תווית 🧮 ונכנסת להיקף «חישובים בלבד». `q` ו-`e` יכולים להכיל HTML (טבלאות נתונים, `<br>` בין שלבי פתרון).
