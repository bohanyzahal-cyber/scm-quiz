# בוחן תרגול — ניהול שרשרת ההספקה למנהלים

תרגול למבחן בקורס **ניהול שרשרת ההספקה למנהלים** (בר-אילן, תואר שני, סמסטר קיץ תשפ"ו), הנלמד במקביל על ידי שני מרצים:
**שלמה ארליך** — תהליכי שרשרת האספקה הארגונית והמודלים הניהוליים (מצגות "שא"), ו**ד"ר ניצן סוויד** — המודלים הכמותיים (חיזוי, מלאי, פארטו, אחזקה, אמינות, חלופות רכש).

**המבחן (לפי הסילבוס): 25 שאלות רב-ברירה, כמותיות ואיכותיות, על כל החומר — 60% מהציון.** ניצן בהרצאה: «במבחן יהיו חישובים, לא מסובכים» — להביא מחשבון.

**▶ [בוחן התרגול](https://bohanyzahal-cyber.github.io/scm-quiz/)** — מצב תרגול עם הסברים, סימולציית מבחן של 25 שאלות, סינון לפי מרצה/נושא, היקף «חישובים בלבד», והדפסה עם תשובות או בלעדיהן.

**▶ [דף נוסחאות ומושגים](https://bohanyzahal-cyber.github.io/scm-quiz/%D7%A0%D7%95%D7%A1%D7%97%D7%90%D7%95%D7%AA.html)** — כל הנוסחאות של ניצן עם דוגמה פתורה, והמודלים של שלמה בעמוד.

## היקף — מה מכוסה ומה עוד חסר

- **שלמה ארליך — מכוסה במלואו:** כל שמונה מצגות "שא" (מבוא, ניהול חומר, מיקור ורכש, ייצור ומיקור חוץ, הזמנות לקוח, לוגיסטיקה, אסטרטגיה וזמישות, ארגז כלים). השאלות נכתבו מהשקפים עצמם — כולל תרשימים שנבדקו כתמונה (פירמידת רמות מיקור החוץ, עץ העלויות הלוגיסטיות, תוכנית העבודה השנתית ועוד).
- **ד״ר ניצן סוויד — מכוסה חלקית:** מצגת 2 (חיזוי) במלואה, כולל שאלות חישוב, והרצאת הפתיחה (אינטגרציה, זמינות ואמינות, שוט השור) מתוך ההקלטה.
- **עוד לא נכלל:** מצגות ניצן 1 ו-3 עד 11 — חיזוי עונתי, רמות מלאי ו-EOQ, מלאי ביטחון ונקודת הזמנה, פארטו, אחזקה ועלויותיה, אמינות, תדירות אחזקה מונעת (שני מודלים) וחלופות רכש. לפי הסילבוס אלה עיקר החלק הכמותי של המבחן.
- **מוסכמות ניצן שנבדקו מול השקפים וההקלטות:** ציר X הוא מספר התקופה; בממוצע נע אין תחזית ל-N התקופות הראשונות; בממוצע נע משוקלל עמודת המשקל צמודה לתקופות (1 לאחרונה, ‎−0.1‎ לכל תקופה אחורה) וכל תחזית מתחלקת בסכום המשקולות של החלון; R ולא R²; MAD ו-MSE בלבד.

## בנייה מחדש

```bash
cd src && python build.py
```

`src/build.py` משבץ את `bank*.js` בתוך `src/template.html` וכותב את `index.html` ואת העותק בתיקיית הקורס, ומעתיק את דף הנוסחאות. בכל בנייה רצות בדיקות מבנה (4 אפשרויות שונות, שדות מלאים, אין כפילויות, אין מסיחים תלויי-מיקום) ובדיקת «תל האורך» — שהתשובה הנכונה אינה בולטת כארוכה או כקצרה ביותר.

### כלי כתיבה (`tools/`)

הבנקים 2, 4, 5, 6, 8 ו-11 נכתבים כקובצי פייתון ב-`tools/data/` — לכל שאלה התשובה הנכונה ושלושה מסיחים — ו-`tools/mkbank.py` מציב את הנכונה במיקום מאוזן וכותב את `src/bankN.js`:

```bash
cd src && python ../tools/mkbank.py ../tools/data/bank5.py bank5.js && python build.py
```

`bank11.py` הוא מחולל שאלות החישוב: כל מספר — התשובה, המסיחים (טעויות נפוצות: N שגוי, שכחה לחלק בסכום המשקולות, משקולות לא צמודות לתקופה) והפתרון בהסבר — מחושב בקוד. שם מוסיפים שאלות חישוב חדשות (למשל EOQ ומלאי ביטחון כשמצגות ניצן ייקראו). הבנקים 1, 3, 7, 9 ו-10 נערכים ישירות ב-JS.

עזרים: `review.js` מדפיס בנק בצורה קריאה; `rank2.py` ו-`longest.py` מראים איפה הנכונה בולטת באורכה; `arrows.py` מחליף חצים לכיוון הקריאה (← ברצפים עבריים, → רק בין מילים לועזיות). בתוך טקסט עברי, נוסחה נעטפת ב-`<bdi dir='ltr'>` כדי שתוצג משמאל לימין.

סכמת שאלה:

```js
{t:"נושא", s:"שלמה | ניצן | הקלטות", q:"השאלה", o:["א","ב","ג","ד"], c:1, e:"הסבר", k:"calc"}
```

`c` הוא אינדקס התשובה הנכונה **לפני** הערבוב (האפליקציה מערבבת את סדר האפשרויות בכל סבב, ולכן אין מסיחים תלויי-מיקום). `k:"calc"` מסמן שאלת חישוב — היא מקבלת תווית 🧮 ונכנסת להיקף «חישובים בלבד». `q` ו-`e` יכולים להכיל HTML (טבלאות נתונים, `<br>` בין שלבי פתרון).
