חיזוי — הנוסחאות מצגת 2 · הרצאות 28.7, 4.8, 11.8

מוסכמות הקורס

  • ציר הזמן: מס"ד תקופות t = 1…n (לא שנים). חוזים לתקופה n+1.
  • Xt = הביקוש בפועל, Ft = התחזית לתקופה t.
  • מחשבים Ft גם לתקופות העבר כדי למדוד סטיות (MAD/MSE) ולבחור שיטה.
  • חמש השיטות שנלמדו: רגרסיה ליניארית, ממוצע נע N=2 / N=3, ממוצע נע משוקלל N=2 / N=3. החלקה מעריכית הוצגה במצגת בלבד.

הגישה הנאיבית שקף 7

Ft+1 = Xt התחזית לתקופה הבאה = הביצוע בתקופה שחלפה.

ממוצע נע פשוט (MA) שקפים 21–23

Ft = (Xt−1 + … + Xt−N) / N אין תחזית ל-N התקופות הראשונות ("מוחקים" אותן). מתאים לביקוש יציב ללא מגמה/עונתיות; חיסרון: מפגר אחרי המגמה.

ממוצע נע משוקלל (WMA) שקפים 24–26

Ft = Σ wi·Xi / Σ wi משקל גבוה לתקופה הדומה ביותר לתקופה החזויה (בדרך כלל האחרונה). המוסכמה של ניצן (שקפים 25–26, הרצאות 28.7 ו-11.8): מוסיפים עמודת Wt צמודה לתקופות — לתקופה האחרונה 1, ובכל תקופה אחורה מפחיתים 0.1 (ליניארית: 1, 0.9, 0.8, 0.7…) או 0.15 (1, 0.85, 0.7…). כל תחזית = סכום (ביקוש × משקל) של N התקופות שבחלון, חלקי סכום המשקולות של אותו חלון. לכן התחזית לתקופה הבאה משתמשת במשקולות 1 ו-0.9 (N=2, סכום 1.9) או 1, 0.9 ו-0.8 (N=3, סכום 2.7), ותחזיות העבר — במשקולות הנמוכות יותר של שנותיהן. סכום המשקולות לא חייב להיות 1.

רגרסיה ליניארית שקפים 14–15, 20

Y = a + b·X b = (nΣxy − Σx·Σy) / (nΣx² − (Σx)²) a = ȳ − b·x̄ R = (nΣxy − Σx·Σy) / √[(nΣx² − (Σx)²)(nΣy² − (Σy)²)] קו הרגרסיה = הקו עם השגיאה המצטברת הקטנה ביותר. אקסל: SLOPE, INTERCEPT, CORREL. R ולא R²: −1 ≤ R ≤ 1; קרוב ל-1 קשר חזק וחיובי, קרוב ל-−1 חזק ושלילי, סביב 0 חלש.

החלקה מעריכית שקפים 27–28

Ft+1 = α·Xt + (1−α)·Ft 0 < α < 1: משקל למכירות האחרונות; (1−α) לתחזית הקודמת. חישוב פשוט, שיטה רגישה. אם אין תחזית התחלתית נהוג F1 = X1.

מדדי דיוק ובחירת שיטה מצגת 2 · שקפים 29–34

MAD — ממוצע הסטיות בערך מוחלט

MAD = Σ|Xt − Ft| / n

MSE — ממוצע ריבועי הסטיות

MSE = Σ(Xt − Ft)² / n מעניש סטיות גדולות יותר מ-MAD.

MRD / MAPE — סטייה יחסית באחוזים

MRD = Σ(|Xt − Ft| / Xt) / n במצגת, אך ניצן אמר להתעלם ממנו במטלה ("תתעלמו מה-MAPE").
n = מספר התקופות שיש להן תחזית בפועל (ב-MA N=3 על 7 תקופות: n = 4). בחירת השיטה: מריצים את הנתונים על כמה מודלים, מחשבים את השגיאה בכל אחד, בוחרים קריטריון (MAD או MSE), ומאמצים את המודל שמביא את הקריטריון למינימום (שקף 33). בקרת תחזית: בוחנים ומעדכנים את המודל כל הזמן — בעיות דיוק נובעות ממודל לא מתאים או מהשפעות חיצוניות (שקפים 30–31).

שלמה — אסטרטגיה וזמישות שא-7

זמישות = זמינות + זריזות + גמישות שקף 15

יכולת התאמה מהירה לנסיבות משתנות ולצעדי המתחרים — "הפתרון לאתגר": התאמת ההיצע לביקוש. Push (ייצור לתחזית/מלאי) ↔ Pull (הזמנת לקוח); נקודת הניתוק = קבלת הזמנת הלקוח (שקף 9). הלקוח הוא חלק מהשרשרת; חומר + מידע + כסף; שרשרת ← רשת (שקף 8).

התאמה אסטרטגית שקפים 17–20

אסטרטגיה ארגונית (איכות / זמן / גמישות / עלות) ← אסטרטגיית שרשרת: יעילה (עלות) ↔ תגובתית (אפקטיביות). ביקוש ידוע ⇔ יעילות; לא ידוע ⇔ תגובתיות. אי-ודאות גבוהה: אי-דיוק תחזית 40–100% (מול ~10%), חוסרים 10–40% (מול 1–2%), עונתיות 10–25%.

מי צריך Agile · המטריצה שקפים 21–22

מודלים מתקדמים · ספקים שקפים 18, 23–35
