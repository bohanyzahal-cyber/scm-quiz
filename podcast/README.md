# פודקאסט — ניהול שרשרת ההספקה למנהלים

אחד עשר פרקים בשני קולות. שישה על המודלים של ד״ר ניצן סוויד, ארבעה על המצגות של שלמה ארליך ופרק חזרה למבחן. כל פרק מסתיים בשאלות לדרך, עם שקט קצר לחשוב לפני התשובה.
התסריטים נכתבו מאותו חומר של הבוחן ודף הנוסחאות (`src/bank*.js`, `נוסחאות.html`), כך שכולם אומרים אותו דבר. כולל הדגשים מההקלטות (היקף החיזוי העונתי למבחן) והטעויות בשקפים.
הצינור הועתק מהפודקאסטים של הקורסים ניהול מערכות תובלה ושינוע ושיטות וכלי ניהול מתקדמים.

| | |
|---|---|
| `mp3/` | קבצי השמע. הם מתפרסמים באתר, ואפשר גם להעתיק אותם לטלפון. |
| `index.html` | דף הנגן. נבנה מחדש בכל הרצה מכל הקבצים שב-`mp3/`. |
| `scripts/` | התסריטים המנוקדים, שמהם נבנה השמע. |
| `scripts/plain/` | אותם תסריטים בלי ניקוד ובכתיב מלא. כאן כותבים ועורכים. אחרי עריכה מעתיקים ל-`scripts/` ומריצים `nikud.py`, וכך נכנסות גם ההחלפות החדשות ב-`nikud-overrides.txt`. |
| `build.py` | ממיר תסריט לקובץ שמע ובונה את דף הנגן. רשימת הפרקים נמצאת בו. |
| `nikud.py` | מנקד שורות חדשות בעזרת Nakdan של דיקטה. |
| `nikud-overrides.txt` | ניקוד ידני שגובר על הניקוד האוטומטי. |

## בנייה

```
cd podcast
cp scripts/plain/07-shlomo-mivne.txt scripts/
python nikud.py 07 --map     # לפני הניקוד: מיפוי מילה->ניקוד לבדיקה, בלי לכתוב
python nikud.py 07           # מנקד את התסריט במקום
python build.py 07           # פרק בודד; דף הנגן מתעדכן תמיד
python build.py --force      # הכל מחדש
```

דרושים `edge-tts` ו-`ffmpeg`. הניקוד והסינתזה מקוונים, ולכן צריך אינטרנט.
כל שורה נשמרת ב-`.cache/` לפי גיבוב של הטקסט והקול, כך ששינוי במשפט אחד מסנתז מחדש רק את השורה שלו.

## פורמט התסריט

```
# title: שם הפרק              <- קובע את שם הקובץ ואת תגית ה-ID3; בלי ניקוד
ש: שורה של המראיינת          <- קול נשי (Hila)
א: שורה של המסביר            <- קול גברי (Avri)
~4                            <- שקט של 4 שניות לפני תשובה
                              <- שורה ריקה = הפסקה קצרה
# הערה                        <- לא נקרא
```

## כללי כתיבה

- **מספרים במילים**, בלי מקפים, וגרש אסקי (`ג'`) ולא גרש עברי. בלי ראשי תיבות עם גרשיים („תוצרת גמורה״, לא תוצ״ג).
- **אותיות וראשי תיבות לועזיים מנוקדים ביד כמילים נפרדות** (אֶם אָר פִּי, וִי אֶם אַיי, תְּרִי פִּי אֶל), ובלי אות שימוש צמודה: „נתחיל מתהליך אֶם אָר פִּי״ ולא „מאֶם...״.
- **קמץ קטן נקרא /a/.** לכן מילים כמו אופנתית, אובדן, חודשיים, אומנות ומחומרי נשארות עם וי״ו ב-`nikud-overrides.txt`, ו„תוכנית״ נכתבת בחולם חסר.
- **את `--map` מריצים לפני הניקוד**, כי אחריו אין בתסריט שורות שדורשות עבודה. ההחלפות בקובץ דורשות את אותן אותיות בדיוק (מותר רק להשמיט אם קריאה). מילה שצריכה כתיב אחר מנוקדת ביד בתוך התסריט, ו-`nikud.py` לא נוגע בה. כך „באפר״ נכתב „בַּפֶר״: בכתיב עם אל״ף הקול אומר „בה אפר״.
- **התאמות לקול** (`tts_safe` ב-`nikud.py`, רץ אוטומטית): דגש על אות שאינה בכ״פ מוסר, כי הקול מוסיף בגללו תנועה. לכן כדאי לבדוק כתיב בבדיקת שמע רק אחרי הצינור המלא: „מִקּוּר״ עם דגש נשמע „מכיר״, ואחרי הסרת הדגש נשמע נכון.
- **טעויות שנמצאו בקורס הזה** ותוקנו בקובץ ההחלפות: מַחְזוֹר (לא מַחֲזוֹר), מִיקּוּר (לא מִיָקוֹר), סַפָּק עם וי״ו החיבור (לא וְסָפֵק), מְגַדֵּר ולְגַדֵּר (לא מִגְדָּר), הַזְמָשָׁה, יְבוּא, הַמּוֹכֵר, קַנְיָן, יֵחָשֵׁף ויִשּׁוּם (שי״ן ימנית), בַּמֶּה (לא בָּמָה).
- **בדיקת שמע**: אחרי הבנייה מתמללים את הפרק ב-faster-whisper ומשווים לתסריט. על מילה חשודה מסנתזים כמה כתיבים במשפט קצר, ובוחרים את מה שנשמע נכון.
